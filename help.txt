roddy - Chrome automation from the command line

Browser lifecycle:
  roddy start [--show] [--insecure | -k] [--extension PATH]
                                  Launch Chrome (headless by default, --show for visible)
                                  --extension loads an unpacked directory or a
                                  .crx/.zip archive; repeat for several
  roddy connect <host:port>      Connect to existing Chrome on remote debug port
  roddy stop                     Shut down Chrome
  roddy status                   Show browser status
  roddy extensions               List extensions loaded into this session
  roddy sw [list]                List extension service workers (exit 1 if
                                  none are running)
  roddy sw eval <expr>           Evaluate JS inside an extension's service
                                  worker; promises are awaited
                                  Flags for both, in any position: --ext ID
                                  picks one extension when several are loaded,
                                  --timeout DUR (default 5s) bounds the wait
                                  for one worker per extension that declares
                                  one. The evaluation itself is bounded by
                                  ROD_TIMEOUT

Navigation:
  roddy open <url>               Navigate to URL
  roddy back                     Go back in history
  roddy forward                  Go forward in history
  roddy reload [--hard]          Reload page (--hard bypasses cache)
  roddy clear-cache              Clear the browser cache

Page info:
  roddy url                      Print current URL
  roddy title                    Print page title
  roddy html [selector]          Print HTML (page or element)
  roddy text <selector>          Print text content of element
  roddy attr <selector> <name>   Print attribute value
  roddy pdf [file]               Save page as PDF

Interaction:
  roddy js <expression>          Evaluate JavaScript expression
  roddy click <selector>         Click an element
  roddy input <selector> <text>  Type text into an input field
  roddy clear <selector>         Clear an input field
  roddy file <selector> <path|-> Set file on a file input (- for stdin)
  roddy download <sel> [file|-]  Download href/src target (- for stdout)
  roddy select <selector> <val>  Select dropdown option by value
  roddy submit <selector>        Submit a form
  roddy hover <selector>         Hover over an element
  roddy focus <selector>         Focus an element

Waiting:
  roddy wait <selector>          Wait for element to appear
  roddy waitload                 Wait for page load
  roddy waitstable               Wait for DOM to stabilize
  roddy waitidle                 Wait for network idle
  roddy sleep <seconds>          Sleep for N seconds

Screenshots:
  roddy screenshot [-w N] [-h N] [file]  Take page screenshot
  roddy screenshot-el <sel> [f]  Screenshot an element

Tabs:
  roddy pages                    List all pages/tabs
  roddy page <index>             Switch to page by index
  roddy newpage [url]            Open a new page/tab
  roddy closepage [index]        Close a page/tab

Element checks:
  roddy exists <selector>        Check if element exists (exit 1 if not)
  roddy count <selector>         Count matching elements
  roddy visible <selector>       Check if element is visible (exit 1 if not)
  roddy assert <expr> [expected] [-m msg]  Assert JS expression (truthy or equality)

Accessibility:
  roddy ax-tree [--depth N] [--json]       Dump accessibility tree
  roddy ax-find [--name N] [--role R] [--json]  Find accessible nodes
  roddy ax-node <selector> [--json]        Show accessibility info for element

Options:
  --local                         Use directory-scoped session (./.roddy/)
  --global                        Use global session (~/.roddy/)
  --version                       Print version and exit
  --help, -h, help                Show this help message

By default, commands auto-detect: if ./.roddy/state.json exists in the
current directory, the local session is used; otherwise the global session.
Use "roddy start --local" to create a directory-scoped session.

Environment:
  RODDY_HOME                     Override data directory (default: ~/.roddy)
  ROD_TIMEOUT                    Timeout in seconds for a single operation,
                                  including a "sw eval" (default: 30)

Exit codes:
  0  Success
  1  Check failed (exists, visible, assert, ax-find or sw found nothing)
  2  Error (bad arguments, no browser, timeout, etc.)
